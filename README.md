💰 Personal Expense Tracker (Excel)
A beginner-friendly 💡 project to help you track your personal expenses using Microsoft Excel 📊.

This simple and effective Excel tracker is designed for individuals who want to start managing their finances efficiently and learn basic Excel skills at the same time.

🔧 Features
📝 Record daily income & expenses

🗂️ Categorize your spending (e.g., Food, Transport, Bills)

📅 Track expenses monthly

📈 View summary charts and insights

🎯 Who is this for?
Beginners in Excel 📘

Students and young adults starting to manage finances 💵

Anyone looking for a simple, offline expense tracking solution

📂 How to Use
Download the Excel file

Open it in Microsoft Excel or compatible software

Start entering your expenses in the provided template

Review charts and summaries auto-generated from your inputs

✅ Tools Used
Microsoft Excel

Basic Excel Formulas

Simple Charts and Conditional Formatting
